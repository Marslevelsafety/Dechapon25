📜 SQL Linter สําหรับมนุษย์

SQLFluff เป็น SQL โอเพ่นซอร์ส มีความยืดหยุ่นต่อสําเนียงและสามารถปรับแต่งได้ ลินเทอร์ ออกแบบโดยคํานึงถึงแอปพลิเคชัน ELT และ SQLFluff ยังรองรับ ทํางานร่วมกับ Jinja Template และ dbt SQLFluff จะแก้ไขอัตโนมัติส่วนใหญ่ ข้อผิดพลาดในการลบเส้น ช่วยให้คุณโฟกัสเวลาไปกับสิ่งที่สําคัญ

เครื่องมือเดียวสําหรับ SQL ที่สอดคล้องกัน
ค้นหาปัญหาด้านสไตล์และไวยากรณ์ตั้งแต่เนิ่น ๆ ใช้วิธีแก้ไขที่ปลอดภัย และปรับกฎให้เข้ากับวิธีการทํางานของทีมคุณ

ขุย
SQLFluff จะค้นหาปัญหาในโค้ด SQL ของคุณและรายงานกลับไป ถึงคุณ (และทีมของคุณ) โดยอัตโนมัติ เพื่อให้การตรวจสอบโค้ดของคุณเป็น เน้นที่ฟังก์ชันมากกว่ารูปแบบ

แก้ไข
SQLFluff ช่วยประหยัดเวลาโดยแก้ไขปัญหา linting ที่พบในโค้ดของคุณ เพื่อประหยัดเวลา และทําให้ SQL ที่สอดคล้องและอ่านง่ายได้ง่าย

แยกวิเคราะห์
SQLFluff จะวิเคราะห์ SQL ของคุณเพื่อจับปัญหาไวยากรณ์หลากหลายโดยไม่ ต้องการเข้าถึงฐานข้อมูล เพื่อที่คุณจะได้ตรวจพบข้อผิดพลาดได้เร็วกว่าใน กระบวนการพัฒนา

กําหนดค่า
SQLFluff สามารถกําหนดค่าให้ทํางานกับภาษา SQL หลากหลายรูปแบบและ การเลือกสไตล์ มันมีการตั้งค่ามาตรฐานที่ชัดเจน ทําให้คุณเริ่มต้นได้ง่าย แต่มีตัวเลือกการตั้งค่าที่ยืดหยุ่นหลากหลายเพื่อให้เหมาะกับสไตล์ท้องถิ่นของคุณ

เริ่มต้นใช้งาน
คุณสามารถเริ่มต้นใช้งาน SQLFluff ในโปรเจกต์ของคุณวันนี้ได้ที่ ดาวน์โหลดจาก PyPi โดยใช้ PIP (หรือ Python ที่คุณชื่นชอบ ผู้จัดการแพ็กเกจ) ดูรายละเอียดเพิ่มเติมได้เลย

สถานีปลายทาง
$ pip install sqlfluff
$ echo "  SELECT a  +  b FROM tbl;  " > test.sql
$ sqlfluff lint test.sql --dialect ansi
